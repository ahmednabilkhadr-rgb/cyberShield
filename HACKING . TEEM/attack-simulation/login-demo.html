    03 / KNOWLEDGE

    Website Spoofing Indicators

    Common URL characteristics that security analysts should inspect during website identity verification.

    DOMAIN IDENTITY

    Lookalike Domains

    Similar-looking domain names may create confusion about the identity of a website.

    URL STRUCTURE

    Misleading URL Components

    User information, unusual subdomains and encoded characters may hide the actual destination.

    PROTOCOL SECURITY

    HTTPS Inspection

    HTTPS protects the connection, but does not independently prove that a website is trustworthy.

    UNICODE SECURITY

    Homograph Indicators

    Some characters from different writing systems can look similar and make domain names confusing.
